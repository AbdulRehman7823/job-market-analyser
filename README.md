
# Job Market Analyser 🇬🇧

A Python data pipeline that analyses UK job market trends to identify 
in-demand skills, salary ranges, and top locations for tech roles.

## 🚀 Live Demo
👉 [Click here to view the live dashboard](https://job-market-analyser-k8ch4yazyzpfostqdb7yx2.streamlit.app/)


## What it does
- Collects and structures job listing data
- Analyses average salaries by job title
- Filters jobs by location (Remote, Manchester, London, etc.)
- Identifies highest paying roles in the market

## Tech Stack
- Python 3.14
- Pandas — data analysis and transformation
- Streamlit — interactive dashboard (coming soon)

## How to run
```bash
git clone https://github.com/AbdulRehman7823/job-market-analyser.git
cd job-market-analyser
pip install -r requirements.txt
python main.py
```a
